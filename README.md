## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Install dependencies:

   ```bash
   npm install
   ```

2. Run the development server:

   ```bash
   ionic serve
   ```

3. Open the local development URL provided in your terminal.

## Production Build

To create a production build, run:

```bash
npm run build
```

## Data Storage

Task data is stored locally in the browser using Local Storage. Data is maintained between page refreshes on the same browser.
